# 안내형 음성 프로필 생성 사양서

> 목적: 사용자가 앱의 안내에 따라 짧은 과제를 수행하면, 노래 음색 변환에 사용할 수 있는 깨끗하고 다양한 개인 음성 데이터셋을 생성한다.
>
> 적용 엔진:
> - 1차: 사용자별 학습이 필요한 RVC
> - 2차: 짧은 reference를 사용하는 Seed-VC

## 1. 목표와 완료 기준

음성 프로필 생성 과정은 다음 조건을 만족해야 한다.

- 유효 녹음 길이: 최소 3분, 권장 4~6분
- 한 사람의 목소리만 포함
- 반주, 악기, 스피커 출력이 포함되지 않은 dry vocal
- 말하기와 노래 발성을 모두 포함
- 사용자의 편한 저음, 중음, 고음을 골고루 포함
- 짧은 음, 지속음, 부드러운 발성, 비교적 강한 발성을 포함
- 클리핑, 심한 배경 잡음, 과도한 리버브가 있는 구간은 제외
- 사용자가 음정이나 가사를 조금 틀리는 것은 허용

프로필은 모든 필수 단계가 통과되고, 전체 유효 녹음이 180초 이상일 때 완료로 판정한다.

## 2. 녹음 환경 안내

녹음 시작 전 다음 안내를 표시한다.

> 조용하고 울림이 적은 장소에서 녹음해주세요.
>
> 반주나 스피커를 끄고, 마이크에서 약 15~25cm 떨어져 주세요.
>
> 녹음하는 동안 마이크와의 거리를 일정하게 유지해주세요.
>
> 너무 크게 소리치거나 무리해서 높은 음을 내지 마세요.

권장 장치 조건:

- 헤드폰 또는 이어폰 사용
- 동일한 마이크와 입력 게인을 전체 과정에서 유지
- 앱의 모니터링 출력은 기본적으로 음소거
- 기준음을 재생하는 단계에서는 기준음 종료 후 300ms 뒤 녹음 시작

## 3. 전체 과정

| 단계 | 내용 | 목표 유효 길이 | 필수 여부 |
|---|---|---:|---|
| 0 | 마이크 점검 및 입력 레벨 설정 | 10초 | 필수 |
| 1 | 자연스러운 말하기 | 40~60초 | 필수 |
| 2 | 모음 지속 발성 | 50~70초 | 필수 |
| 3 | 음역 탐색과 음계 따라 부르기 | 50~80초 | 필수 |
| 4 | 안내 멜로디 따라 부르기 | 60~90초 | 필수 |
| 5 | 자유 노래 | 60~120초 | 필수 |
| 6 | 결과 확인 및 부족 구간 보충 | 가변 | 필수 |

전체 소요 시간은 안내와 재시도를 포함해 약 7~10분을 목표로 한다.

## 4. 단계별 안내 및 대본

### 단계 0. 마이크 점검

화면 안내:

> 편한 목소리로 “안녕하세요, 지금부터 제 목소리를 녹음합니다”라고 말해주세요.

녹음:

- 최대 10초
- 처음 1초의 환경음을 별도로 측정
- 발화 중 입력 레벨과 클리핑 검사

통과 조건:

- 발화 구간 peak: -12~−3 dBFS 권장
- 절대 peak: -1 dBFS 미만
- 발화 RMS와 환경음 RMS 차이: 최소 20dB 권장, 15dB 미만이면 경고
- 유효 발화: 최소 3초

실패 안내:

- 입력이 작음: “마이크를 조금 가까이 하거나 입력 음량을 높여주세요.”
- 클리핑: “목소리가 너무 크게 입력됩니다. 마이크에서 조금 멀어져 주세요.”
- 잡음 과다: “주변 소음이 큽니다. 더 조용한 장소에서 다시 시도해주세요.”

### 단계 1. 자연스러운 말하기

목표:

- 자음과 모음의 다양한 조합 수집
- 노래와 다른 자연스러운 사용자 음색 확보

사용자가 아래 문장을 자연스럽게 읽게 한다. 문장마다 개별 클립으로 녹음한다.

1. “오늘은 내 목소리로 노래를 만들기 위한 음성 샘플을 녹음합니다.”
2. “바람이 불어오는 길을 따라 천천히 걸으며 주변의 소리를 들어봅니다.”
3. “기쁘고 밝은 순간도 있고, 조용하고 차분한 순간도 있습니다.”
4. “봄에는 따뜻한 햇살이 비치고, 여름에는 시원한 비가 내립니다.”
5. “가나다라마바사, 아자차카타파하.”
6. “빠르게 말하지 않고, 평소 사용하는 편안한 목소리로 읽겠습니다.”

규칙:

- 문장당 최대 2회 재시도
- 발음을 조금 틀려도 유효
- 웃음, 기침, 외부 소리가 겹치면 해당 문장만 재녹음

### 단계 2. 모음 지속 발성

목표:

- 사용자의 공명과 포먼트 특성 확보
- 안정적인 지속음 확보

화면에 모음과 남은 시간을 크게 표시한다.

각 모음을 편한 음높이로 3초씩 2회 발성한다.

```text
아——
에——
이——
오——
우——
```

그 다음 `아`, `에`, `오`를 각각 다음 높이로 발성한다.

- 편한 음보다 조금 낮게 3초
- 편한 음으로 3초
- 무리하지 않는 범위에서 조금 높게 3초

규칙:

- 음정이 완전히 고정되지 않아도 허용
- 음 시작과 끝의 자연스러운 흔들림 허용
- 목이 갈라지거나 과도하게 힘준 경우 재녹음 권장
- 비브라토는 허용

### 단계 3. 음역 탐색과 음계 따라 부르기

목표:

- 사용자의 안전하고 자연스러운 음역 추정
- 저음·중음·고음 발성 확보

#### 3.1 편한 기준음 찾기

앱이 중간 음역의 기준음을 하나씩 재생한다. 사용자는 `아`로 따라 부른다.

- 남성 시작 후보: C3
- 여성 시작 후보: C4
- 성별을 입력받지 않고, 사용자가 편한 시작 음역을 선택하거나 간단한 탐색으로 자동 결정
- 탐색 범위: C2~C5

사용자가 “편함 / 낮음 / 높음”을 선택할 수 있게 한다.

#### 3.2 5음 음계

편한 기준음을 중심으로 다음 패턴을 `아`로 부른다.

```text
1–2–3–4–5
5–4–3–2–1
1–3–5–3–1
```

각 패턴은 다음 세 음역에서 수행한다.

- 편한 음역
- 편한 음역보다 3~5반음 낮은 음역
- 편한 음역보다 3~5반음 높은 음역

판정:

- 목표 음정과 정확히 일치할 필요 없음
- 옥타브를 잘못 따라 하면 재안내
- 연속적인 무성음 또는 음정 검출 실패가 40%를 넘으면 재시도
- 사용자가 불편함을 누르면 높은/낮은 과제를 즉시 생략하고 안전 음역으로 복귀

### 단계 4. 안내 멜로디 따라 부르기

목표:

- 실제 노래에 가까운 자음·모음·음정 전환 확보
- 짧은 음과 긴 음, 음정 도약을 함께 확보

앱이 반주 없이 기준 멜로디를 먼저 재생하고, 재생이 끝난 뒤 사용자가 부르게 한다. 기준음과 사용자 목소리가 녹음에 동시에 들어가지 않도록 한다.

권장 과제:

1. 짧고 밝은 프레이즈 — 8~12초
2. 길게 끄는 음이 있는 프레이즈 — 8~12초
3. 낮은 음에서 높은 음으로 이동하는 프레이즈 — 8~12초
4. 음정 도약이 있는 프레이즈 — 8~12초
5. 부드럽게 시작하고 조금 강하게 끝나는 프레이즈 — 8~12초

권장 가사:

```text
오늘의 바람이 나를 불러
멀리 빛나는 길을 따라서
조용히 마음을 열어 보면
우리의 노래가 다시 피어나
```

각 프레이즈는 의미보다 발음 다양성과 발성 형태를 우선한다. 저작권 문제가 없는 자체 제작 멜로디와 가사를 사용한다.

규칙:

- 음을 조금 틀리거나 박자가 어긋나도 허용
- 원래 멜로디와 전혀 다른 음역으로 부르면 한 번만 재시도
- 사용자가 가사를 틀려도 발성이 깨끗하면 수집 가능

### 단계 5. 자유 노래

화면 안내:

> 반주 없이 편한 노래를 1~2분 정도 불러주세요.
>
> 완벽하게 부를 필요는 없습니다. 편한 저음과 중음, 가능한 경우 자연스러운 고음도 포함해주세요.

규칙:

- 저작권이 있는 노래도 학습 입력으로는 받을 수 있으나, 원본 녹음에는 반주가 포함되면 안 됨
- 한 곡을 계속 부르거나 여러 곡을 나눠 불러도 됨
- 최대 클립 길이 30초로 자동 분할
- 기침, 말실수, 긴 무음은 구간 단위로 제외 가능

## 5. 실시간 품질 검사

각 클립은 녹음 직후 다음 항목을 검사한다.

| 검사 항목 | 통과 | 경고 | 실패 |
|---|---:|---:|---:|
| peak | -12~−3 dBFS 권장 | -18~−12 또는 −3~−1 dBFS | -18 dBFS 미만 또는 -1 dBFS 이상 |
| 클리핑 샘플 비율 | 0% | 0~0.05% | 0.05% 초과 |
| 발화/환경 SNR 추정 | 20dB 이상 | 15~20dB | 15dB 미만 |
| 유효 음성 비율 | 70% 이상 | 50~70% | 50% 미만 |
| 연속 무음 | 2초 미만 | 2~4초 | 4초 초과 |
| 리버브 | 낮음 | 중간 | 심함 |

`경고`는 사용자가 결과를 듣고 유지할 수 있다. `실패`는 기본적으로 재녹음을 요구하되, 건너뛰기 가능한 보조 과제에서는 제외할 수 있다.

## 6. 프로필 완료 화면

다음 정보를 시각화한다.

- 총 녹음 길이
- 유효 녹음 길이
- 말하기 / 지속음 / 음계 / 안내 멜로디 / 자유 노래별 길이
- 수집된 음역의 최저음과 최고음
- 평균 잡음 수준
- 재녹음이 권장되는 클립

완료 예시:

```text
음성 프로필 준비 완료

유효 음성: 4분 38초
수집 음역: A2 ~ E4
클립 수: 42개
품질: 좋음

이 데이터로 개인 보컬 모델을 만들 수 있습니다.
```

## 7. 저장 형식

### 7.1 로컬 디렉터리

```text
voice_profiles/
└── <profile_id>/
    ├── manifest.json
    ├── raw/
    │   ├── speaking_001.wav
    │   ├── vowel_a_mid_001.wav
    │   ├── scale_mid_up_001.wav
    │   ├── guided_phrase_001.wav
    │   └── free_singing_001.wav
    └── accepted/
        └── 품질 검사를 통과한 클립
```

### 7.2 오디오 규격

- WAV PCM
- mono
- 48kHz로 원본 보관
- 24-bit 권장, 장치 미지원 시 16-bit 허용
- 서버 전송 또는 RVC 전처리 시 엔진 요구 sample rate로 변환
- 정규화와 노이즈 제거 전 원본도 보존

### 7.3 manifest 필수 필드

```json
{
  "schema_version": 1,
  "profile_id": "uuid",
  "created_at": "ISO-8601",
  "input_sample_rate": 48000,
  "clips": [
    {
      "file": "accepted/guided_phrase_001.wav",
      "category": "guided_singing",
      "prompt_id": "guided_phrase_001",
      "duration_sec": 10.4,
      "peak_dbfs": -4.2,
      "snr_db": 24.8,
      "voiced_ratio": 0.87,
      "pitch_min_hz": 130.8,
      "pitch_max_hz": 329.6,
      "quality": "pass"
    }
  ]
}
```

## 8. 엔진별 데이터 사용

### RVC

- `accepted/`의 모든 통과 클립을 사용
- 권장 유효 길이: 4~10분
- 말하기만으로 구성하지 않고 노래 발성을 최소 60% 포함
- 전처리 단계에서 3~4초 단위로 재분할
- 잡음이 심한 클립은 학습에서 제외

### Seed-VC

- 전체 데이터 중 가장 깨끗하고 자연스러운 15~25초를 선택
- 사용하려는 곡과 비슷한 음역의 노래 구간을 우선
- 긴 무음과 음정이 심하게 깨진 구간 제외
- 여러 클립을 연결할 때 100~200ms 무음을 삽입

## 9. 오류 및 중단 처리

- 각 단계가 끝날 때 진행 상황을 저장
- 앱 종료 후 마지막 완료 단계부터 재개
- 마이크 장치가 바뀌면 레벨 점검을 다시 수행
- 사용자에게 개별 클립 재생·삭제·재녹음 기능 제공
- 서버 업로드 실패 시 로컬 데이터를 유지하고 재시도
- 학습 시작 전 예상 소요 시간과 서버 업로드 여부 표시

## 10. 개인정보 및 동의

음성은 개인 식별 가능성이 높은 생체성 데이터로 취급한다.

- 녹음 시작 전에 수집 목적과 서버 업로드 여부를 명시
- 원본 음성 보관 기간과 삭제 방법 제공
- 사용자 동의 없이 다른 모델 학습에 재사용하지 않음
- 서버 전송 시 TLS 사용
- profile ID는 사용자 실명 대신 임의 UUID 사용
- 사용자가 프로필과 학습 모델을 함께 삭제할 수 있어야 함

## 11. 이번 수동 재녹음용 최소 절차

현재 RVC 재시험을 위해서는 다음 구성으로 하나의 WAV 또는 여러 WAV를 준비한다.

1. 위 말하기 문장 6개: 약 1분
2. `아/에/이/오/우` 지속음과 낮음·중간·높음 발성: 약 1분
3. 편한 음역의 상행·하행 음계: 약 1분
4. 무반주 노래: 최소 2분

총 5분 이상을 권장한다. 틀린 음과 가사는 허용하지만, 반주·클리핑·심한 잡음·과도하게 힘준 발성은 피한다.
